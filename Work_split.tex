{\Large\bfseries Spectral line diagnostics -- proposed work split}\hfill{\small M2 IRT, MC ``Radiation'' 2026--27}

\textbf{Goal.} Tool that (1) identifies lines in a spectrum, (2) measures equivalent widths above the continuum, (3) uses curves of growth to derive $z$, $N$, $b$ per species. \textbf{Check-ins:} Oct 14, Nov 18. \textbf{Oral:} Dec 9 (50\% of grade, may be individual).

\textbf{Scope.} Python; main target UV/optical quasar absorption spectra (Voigt profiles, HI + metals); code kept generic for a second-domain demo (e.g.\ 21\,cm) at the end.

\begin{tabular}{@{}p{8.2cm}@{\hspace{0.4cm}}p{8.2cm}@{}}
\toprule
\textbf{A -- data $\to$ lines} & \textbf{B -- lines $\to$ physics}\\
\midrule
\begin{itemize}
\item Load spectra (FITS/ASCII), archive queries
\item Continuum fit and normalisation
\item Atomic line list ($\lambda$, $f$, $\Gamma$)
\item Line detection and redshift identification
\item Interactive visualisation
\end{itemize}
&
\begin{itemize}
\item Voigt profile, optical depth $\tau(\lambda;N,b,z)$, LSF
\item Equivalent widths with error propagation
\item Theoretical curves of growth; multi-line fit of $N$, $b$
\item Uncertainties ($\chi^2$ grid / MCMC / bootstrap)
\end{itemize}\\
\bottomrule
\end{tabular}

\textbf{Interface.} A outputs a normalised spectrum (flux, error) plus a line table per absorber: species, $\lambda_\text{rest}$, $f$, $z_\text{guess}$, window. B only needs this. Shared Python classes \texttt{Spectrum}, \texttt{Line}, \texttt{Absorber}, agreed in week 1.

\textbf{Avoiding the dependency.} At first B works on \emph{synthetic spectra} (known $z,N,b$, so the truth is known) with a hand-made line table. A's automatic identification later produces the same table; B's code does not change. Fallback: identify lines by hand in one real spectrum.

\textbf{Shared work.} Repo and interfaces; synthetic spectrum generator (early); validation (inject known $z,N,b$, check recovery in linear, saturated and damped regimes; COG limits $W\propto N$ and $W\propto\sqrt N$); report and slides (each presents own half).
