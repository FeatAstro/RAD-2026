\textbf{Identification by a comb.} A shift multiplies all wavelengths by the same factor, $\lambda_{\rm obs}=\lambda_{\rm rest}(1+z)$, so the \emph{ratios} of the wavelengths of one species are fixed. Each species is a comb of rest wavelengths (NIST); each detected feature is tried as each tooth, which gives a candidate velocity ($-600$ to $+600$\,km/s). A comb defines a system if at least 3 teeth land on features within 15\,km/s, with EW ratios between the $f\lambda$ ratio (weak lines) and 1 (saturated), and no stronger tooth missing. Every species is then labelled at the system velocity (10\,km/s), single-line species included. On 3C\,273: one system, the Milky Way at $-12.7$\,km/s, 19 of 44 features labelled.

\textbf{Interface: the features table} (full description in the docstring of the package \texttt{spectral\_diag.detect}). \texttt{find\_features(spectrum, threshold=4.0, sign=-1)} returns an astropy \texttt{Table}, one row per feature, columns \texttt{wave}, \texttt{wave\_err}, \texttt{wave\_min}, \texttt{wave\_max} (\AA, vacuum), \texttt{depth}, \texttt{ew}, \texttt{ew\_err} (\AA), \texttt{snr}. \texttt{identify} adds \texttt{species}, \texttt{line}, \texttt{wave\_rest}, \texttt{v} (km/s). Each side can be written and tested without the other: \texttt{detect} is a package with one module per job, and \texttt{identify} goes in its own module \texttt{detect/identify.py}, re-exported by the package.
