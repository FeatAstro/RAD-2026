\textbf{Identification by a comb.} A shift multiplies all wavelengths by the same factor, $\lambda_{\rm obs}=\lambda_{\rm rest}(1+z)$, so the \emph{ratios} of the wavelengths of one species are fixed. Each species is a comb of rest wavelengths; we slide it over the detected features (trial velocity $v$, $-600$ to $+600$\,km/s for a star) and count the teeth that hit a feature. Hydrogen's comb comes from the Rydberg formula, $1/\lambda = R_H(1/n_{\rm low}^2-1/n_{\rm up}^2)$; other species from a table (NIST). Strength ratios reject chance matches: a strong line predicted but missing excludes the species; doublets (CaII H\&K, NaD) must have EW ratios between 2:1 (weak) and 1:1 (saturated). Telluric O$_2$/H$_2$O bands are one more ``species''.

\textbf{Interface: the features table} (full description in the docstring of the package \texttt{spectral\_diag.detect}). \texttt{find\_features(spectrum, threshold=4.0, sign=-1)} returns an astropy \texttt{Table}, one row per feature, columns \texttt{wave}, \texttt{wave\_err}, \texttt{wave\_min}, \texttt{wave\_max} (\AA, vacuum), \texttt{depth}, \texttt{ew}, \texttt{ew\_err} (\AA), \texttt{snr}. \texttt{identify} adds \texttt{species}, \texttt{line}, \texttt{wave\_rest}, \texttt{v} (km/s). Each side can be written and tested without the other: \texttt{detect} is a package with one module per job, and \texttt{identify} goes in its own module \texttt{detect/identify.py}, re-exported by the package.
